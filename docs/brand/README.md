# Brand

Hand-authored SVG. Every PNG here is rendered from the SVG next to it by
`scripts/video/logo.py` plus `scripts/video/shoot-logo.mjs`, so the SVG is the source and the PNG is
a build artefact.

| File | Use |
|---|---|
| `mark-dark` | Square icon on dark. The default |
| `mark-light` | Square icon on a white page |
| `mark-bare` | Transparent, no plate, for placing on anything |
| `lockup-dark` / `lockup-light` | Horizontal lockup with the wordmark |
| `cover` | 1920x1080 title card |

## The mark

Three nodes, two hops, arranged so the path itself forms a check.

That is the product's own argument rather than a decoration: three agents, each approved on its own,
connected into a chain. The second hop is orange because it is the one that reaches the irreversible
action, and the third node is the one nobody was looking at. It reads as *verified* at a glance and
as *a path* once you look.

No gradients and no fine detail in the mark, so it survives a favicon and a one-colour print.
