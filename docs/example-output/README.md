# Example output

Everything here was generated by one command, against the three fixtures in this repository:

```bash
preflight scan fixtures --policy policy.example.yaml --fail-on none \
  --dossier docs/example-output/dossier \
  --sarif   docs/example-output/preflight.sarif \
  --cyclonedx docs/example-output/agentbom.cdx.json \
  --out     docs/example-output/bom
```

It is committed so you can read the output before deciding whether to install anything. Regenerate
it with the same command; it is deterministic, so a clean checkout reproduces these files byte for
byte unless the fixtures or the rules change.

| Path | What it is |
|---|---|
| `dossier/*.md` | The governance dossier, one per agent. Template v1.0 |
| `dossier/*.svg` | The trust graph each dossier embeds, drawn from the bill of materials |
| `preflight.sarif` | SARIF 2.1.0, the file GitHub code scanning ingests |
| `agentbom.cdx.json/*.cdx.json` | CycloneDX 1.6, validated in CI against the vendored schema |
| `bom/*.json` | The AgentBOM each of the above is derived from |

## What to look at first

**The dossier admits what it cannot derive.** Owner, sponsor, purpose and intended use all read
*requires human input* rather than a plausible sentence. A governance document that invents its own
evidence is worse than no document, so those fields are left for a person.

**The trust graph is drawn, not described.** The chain runs Inbox triage (M365 declarative) to
Contract router (Copilot Studio) to records-agent (Foundry), and each edge carries how it was
resolved and what authentication it used. The orange labels are irreversible actions with no
declared human gate.

**Severity is gated on evidence.** In the SARIF, a path is critical only when every edge is proven
or matched and the sink's irreversibility is declared. Where an edge was only assumed, the finding
is reported at a lower severity and says so, with its own rule descriptor so the downgrade is
visible rather than hidden.

**`secretRef: "inline"` in the BOMs is a finding, not a secret.** It records that the credential is
stored in the agent definition instead of a vault. No credential material appears in any file here.

## The composition hash

Each dossier carries a composition hash and a serial derived from it. Change any part of the
composition and both change, which is what voids a certification. Two scans of an unchanged estate
produce the same hash, so a diff between two dossiers is a real change rather than noise.
